# Работа над выпуском «Гильдии Теней»

Перед изменениями прочитайте `docs/RELEASE_ARCHITECTURE_RU.md` и
`docs/release/TEAM_HANDOFF_RU.md`. Пакеты, зависимости и GitHub-задачи:
`docs/release/WORK_PACKAGES.json` и `docs/release/GITHUB_ISSUES.json`.

- Основной разработчик ведёт архитектуру, общие контракты и интеграцию.
  Команда работает над назначенным пакетом и указанными путями; общие файлы
  меняются по правилам владения из инструкции передачи.
- Проверяйте актуальную ветку/базовый SHA и комментарии задачи. Непроверенный
  PR №16 не считается готовой релизной базой. Не включайте посторонние правки.
- Источник игровых правил — согласованный текущий объём. `docs/history/`
  и ранний `docs/expedition-design.md` не разрешают возвращать отменённые механики.
- Принятый пользователем арт сохраняется. Перерисовка — по конкретной
  согласованной правке; техническая нормализация и новые детали рисунка различаются.
  Генерируемые `art-sources/poses/*/masters/` не добавляются в Git.
- Проверки и артефакты относятся к конкретному commit. Записывайте фактический
  результат и ограничения: модульный тест не заменяет браузер, SDK-заглушка —
  черновик площадки, эмуляция viewport — реальный телефон.
- PR содержит ID пакета, результат, проверки и оставшиеся блокеры. Не объединяйте
  PR с незакрытыми обязательными проверками. Публикация требует отдельного решения
  владельца продукта.

Решения и порядок работ, явно изменённые пользователем, имеют приоритет;
обновляйте план и задачу, чтобы следующие исполнители видели актуальные вводные.
