# Работа с репозиторием

Браузерная игра «Гильдия Теней», TypeScript и Vite. Общая структура и команды — в `README_RU.md`.

Для продолжения работы команды T2 прочитайте `docs/T2_HANDOFF_RU.md`, затем сверьте
контекст с текущими `git status`, веткой и историей коммитов. Файл передачи описывает
конкретную ветку T2; задачи других команд определяются их текущим запросом.

Основные проверки кода:

```bash
npm run typecheck
npm test
npm run build
npm run build:yandex
```

`dist/`, `dist-yandex/`, `node_modules/`, `qa-saves/` и `qa-out/` — генерируемые каталоги.
Коммитить следует исходники, инструкции и необходимые отчёты приёмки.

Сохранения используют схему v2. Перед изменением формата изучите `src/core/save.ts`
и миграции активного забега. Ограничения и инварианты платформенной части описаны
в `docs/PLATFORM_RELIABILITY_RU.md`.

Браузерные QA-скрипты используют `CHROME` для пути Chromium. Проверки с имитацией SDK
подтверждают поведение приложения; настоящие реклама, облако Яндекса и производительность
физического телефона требуют отдельной приёмки. Исторические отчёты сохраняйте с их датами.
