# Интеграция Брана — пилот v0.4 (игра v1.8)

## Что подключено

- Скелет DragonBones 5.5 (`rigs/bran/bran_ske.json`, `bran_tex.json`, `bran_tex.webp`), 14 костей / 14 слотов, шесть клипов при 24 FPS (`idle`, `attack`, `cast`, `hit`, `death`, `victory`).
- События `impact` в `attack` на кадре 10 и `cast` на кадре 7.
- Новый портрет `heroes/bran/portrait_pilot_v04.webp`, выбранный через `art-pack.json`; старый `heroes/bran/portrait.webp` остаётся нетронутым.
- Четыре слоя обычных катакомб: `crypt_far`, `crypt_mid`, `crypt_floor`, `crypt_front`; арена босса не изменяется.
- В `ArenaScene.stats().units[]` добавлен флаг `rig`, чтобы QA мог отличить реальный DragonBones от процедурной анимации.
- Другие герои и противники не затрагиваются, их fallback-анимация сохраняется.

## Механика выбора арта

При запуске `loadArtPack()` считывает `public/art/v17/art-pack.json`, затем асинхронно подгружает JSON DragonBones. Путь портрета разрешается относительно этого же реестра. Функция `artPortraitFor(group, id)` возвращает переопределение или `null`; UI продолжает использовать обычный портрет, когда переопределения нет. Неудачная загрузка изображения возвращает прежнюю эмблему роли.

## Рекомендуемые проверки в репозитории

```bash
npm ci
npm run typecheck
npm test
node tools/art/validate_pack.mjs public/art/v17/art-pack.json --strict
npm run build
npm run qa:saves
npm run dev -- --host 127.0.0.1 --port 5173
# в другом терминале:
node tools/qa/bran-pilot.mjs http://127.0.0.1:5173/ qa-saves/battle.json qa-out/bran-pilot
```

Для последней проверки нужен Playwright Chromium; при другом расположении браузера укажите `CHROME=/path/to/chrome`. Для проверки запасного Canvas 2D повторите команду с `QA_FORCE_CANVAS=1` (скрипт намеренно отключает WebGL в тестовом контексте).

Браузерный тест открывает **реальную игру** (не автономный просмотрщик) на 1920×1080, 1366×768, 1024×768 и 390×844; проверяет, что актёр Брана действительно рисуется через риг, новый портрет загружен, в журнале ошибок сцены пусто, нет ошибок JavaScript / HTTP и сохранены снимки. Финальные позы художественно оцениваются отдельно.

## Ограничения и блокеры художественной приёмки

**Статус: интеграционный пилот, не финально принятый арт.** Рабочая поставка v0.4 создана из AI-концепт-листа, технически разрезана на части, но требует ручной дорисовки суставов и окончательной анимации падения. Нативный DragonBones `.dbproj` не входит в комплект, доступны редактируемые `.ora`, а не PSD/KRA. QA-плеер из поставки — дополнительный наглядный инструмент; его скриншоты не доказывают работоспособность внутри игры. Проверки запуска в настоящей игре должны быть выполнены в Codex после применения патча.

## Откат

Устанавливать только в отдельной ветке, не в `main`. Перед установкой убедиться, что рабочая ветка чистая (`git status --short`). Для полного отката предпочтительно удалить созданную ветку или отменить отдельный интеграционный коммит с помощью `git revert <sha>`. Старые ассеты проекта не перезаписываются. Папка `art-sources/bran-v04/` содержит исходники, не включаемые в веб-сборку.
