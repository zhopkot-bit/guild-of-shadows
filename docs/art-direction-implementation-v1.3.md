# Art Direction Implementation v1.3

## Утверждённая художественная цель

Главным визуальным эталоном остаются Dark Fantasy концепт-арты проекта: огромная готическая цитадель, холодный лунный свет, туман, локальные источники тёплого света, детализированные герои и враги, чернильные UI-панели с латунной окантовкой. Ранее предоставленные пользователем изображения и другие ветки проекта не являются базой этого направления.

## Реализовано в исходниках

1. Кропы из concept pack конвертированы в оптимизированные WebP и подключены как публичные ассеты.
2. Экран гильдии получил hero-banner цитадели и карточки построек с артами.
3. Экран отряда получил шапку с героями и растровые портреты персонажей.
4. Экран экспедиции получил сцену руин; маршрут карты размещается поверх затемнённой сцены с SVG-соединениями и настоящими интерактивными узлами.
5. Арена обычного боя использует фон крипты; босс переключает фон между формами первой и второй фазы.
6. CSS расширен для планшетного/desktop viewport: в широком режиме доступны сетка построек в три колонки, двухколоночный список героев и более широкая арена.
7. Загрузка портретов имеет fallback на прежние SVG/монограммы, если растровый файл недоступен.

## Принципы визуального качества

- Изображение должно задавать композицию, но не забирать контраст у кнопок, метрик и игровых предупреждений.
- Не помещать критический текст на самый светлый участок фона.
- Цвет не является единственным различителем угрозы: используются подписи, иконки и телеграф.
- Не заменять действующую логику карт/кнопок цельными скриншотами: карта, интерактивные элементы и боевые статусы остаются реальными DOM-компонентами.
- Релизные кадры должны пройти проверку на узком мобильном экране и при увеличенном системном шрифте.

## Что пока не следует считать законченным

- Растровые герои и здания — оптимизированные кропы из concept sheets, а не финальные разделённые production masters.
- Арена и фоновые сцены подключены в код, но реальный запуск Vite/browser capture не подтверждён: npm install не завершился по тайм-ауту в рабочем окружении.
- PNG в `Art_Direction_Preview` являются дизайнерскими постановочными макетами, а MP4 — слайд-шоу этих экранов. Они показывают целевой визуальный язык, но не доказывают идентичную верстку или поведение в рантайме и не являются записью gameplay.
- Нужна отдельная интеграция/проверка анимаций смены фазы и экранных переходов на устройстве.

## Проверка

`tsc -p tsconfig.src.json` — PASS после внедрения ресурсов. Проверка путей к ассетам и ZIP integrity должна выполняться при выпуске архива. `npm test` и `npm run build` нельзя объявлять пройденными до установки зависимостей.
