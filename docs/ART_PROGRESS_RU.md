Обновление порядка работ от 29.10.2026: сначала готовится художественный комплект по `ARTIST_BRIEF_RU.md`; техническая интеграция, экспортные бюджеты, проверки в игре и общий регрессионный прогон выполняются в конце для всего комплекта. В процессе оцениваем сам рисунок: канон, анатомию, оружие, силуэты и согласованность поз.

Бран принят; возможные художественные правки отложены на завершающий этап. Для Миры создан комплект из восьми поз, последняя атака v9 принята. Уже сделанная техническая интеграция Миры сохранена в PR №15.

## Очередь художественной работы

1. Рук: `idle`, `aim`, `shoot`, `hit`, `down`, `victory` — шесть кандидатов созданы, художественная приёмка открыта.
2. Нора: семь кандидатов созданы, художественная приёмка открыта.
3. Гоблин-налётчик и пепельный волк: по пять кандидатов созданы; у волка осталась серая подложка, подготовка прозрачности впереди. Костяной страж и пепельный чародей: по шесть кандидатов созданы, художественная приёмка открыта.
4. Костяной король: первая и вторая фазы — по шесть кандидатов созданы; рукоять и замах переработаны по замечанию пользователя. Художественная приёмка открыта.
5. Катакомбы и тронный склеп: художественные мастера и четыре слоя каждой арены.
6. P1: портреты по необходимости и по ТЗ, шесть событий, иконки модулей, узлов и ресурсов.
7. P2: цитадель, пять постов, групповой арт при изменении обликов, промо и VFX по ТЗ.
8. Общая художественная доводка и затем единый технический этап.

Исходники и запросы сохраняются по персонажам. Созданный рисунок не помечается принятым без решения пользователя. Проверки игрового рендерера на каждом новом персонаже больше не запускаются.
