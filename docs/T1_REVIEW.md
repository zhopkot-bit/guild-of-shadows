# T1 — материалы к рецензии

Дата: 04.11.2026. База: `17d7070`, ветка `t1/gameplay-integrity-and-sdk-pause`.
Изменения готовы к рецензии и подготовке слияния по результатам локальной приёмки
официального SDK dev-адаптера. Сетевой 403 снят. Владелец подтвердил, что черновика
в Яндекс Играх пока нет, и попросил выполнить доступную проверку в этой среде.
Реальное облако, live-реклама и события площадки проверяются после создания черновика,
до публикации; локальная приёмка их не подтверждает.

## Поведение после изменения

- Загрузка не принимает повторяющихся участников, некорректную глубину, битые
  ссылки карты/очереди/журнала, неполные стадии и повреждённый RNG.
- Повреждённый activeRun очищается только после создания копии исходного сейва.
  При отказе резервной записи перезапись прогресса отключается; гильдия не обнуляется.
- Вход в узел, исход/продолжение события и rewarded-воскрешение сохраняются сразу.
- SDK, вкладка, модальное окно и рекламный ролик независимо удерживают паузу.
  Она распространяется на бой, звук, экономику и режим «Досчитать». Старый View
  после закрытия не применяет незавершённое действие.
- Подписка SDK выполняется до ожидания игрока. GameplayAPI.start следует после
  LoadingAPI.ready и отражает активную экспедицию и общую паузу.
- Победа завершает семь узлов, включая небоевые. Засада и элитная награда не
  добавляют второй узел; проигранный бой не завершает текущий. Старые активные сейвы
  получают корректный счётчик, уже выданные исторические итоги сохраняются.

Формат GameState остаётся v2; `completedNodes` необязателен для старых сейвов.
Параметры баланса, составы встреч и ассеты не менялись.

## Локальная SDK-приёмка — 04.11.2026

Использован официальный `@yandex-games/sdk-dev-proxy@0.0.2` с production-сборкой
игры и `--dev-mode`. Пакет установлен в `work/yandex-sdk`, вне зависимостей игры.
`tools/qa/yandex-dev-server.cjs` запускает пакет без изменения его исходников:
заменяет только локальный TLS-сертификат на именной и отключает автоматическое
открытие браузера. Прокси среды сохраняется через `node --use-env-proxy`;
глобальная проверка TLS не отключается, Chromium доверяет только ключу локального
сертификата. SDK, его методы, callback'и и сетевые ответы в QA не подменяются.

Старый `HTTP 403 Domain forbidden` больше не воспроизводится. Официальный адаптер
с `http://yastatic.net/s3/games-static/sdk-dev/yandex-dev-adapter.js` и локальный
`/sdk.js` отвечают **HTTP 200** с одинаковым SHA-256:
`b0e5af365b02f7afed31efa0a03f9527fc0a1d4cbf0f19738a771581e76e4cc5`.
Загрузчик `https://games.s3.yandex.net/sdk.js` также доступен (HTTP 200), но для
инициализации требует iframe площадки; прямой standalone-запуск его не заменяет.

`tools/qa/yandex-live.ts` проходит начальный probe: платформа `yandex`, ошибок
JavaScript нет. Отчёт теперь явно указывает `scope: initialization-only`,
`sdkRuntime: official-dev-adapter` и `platformAcceptance: not_run`.

`tools/qa/yandex-dev-flow.ts` проверяет при 1366×768:

- Production-приложение использует `YandexPlatform`; `LoadingAPI.ready` предшествует
  `GameplayAPI.start`.
- Раннее закрытие официального rewarded-окна не воскрешает героя и не расходует лимит.
- Открытая реклама останавливает доход и GameplayAPI; закрытие возобновляет их.
- Досмотр официального rewarded-окна воскрешает героя с 30% HP ровно один раз;
  состояние и израсходованный лимит сохраняются сразу.
- После фактического `setData` удаляется игровая копия `gos.save`: перезагрузка
  восстанавливает тот же забег через `getData` dev-адаптера.
- Rewarded на итогах добавляет ровно одну исходную награду золотом. Флаг удвоения
  сохраняется; перезагрузка не повторяет начисление и не возвращает кнопку.
- Для fullscreen, пока не вызываемого UI, отдельно собирается исходный
  `YandexPlatform`: настоящие callback'и dev-адаптера включают/снимают рекламную
  паузу, перекрывающий rewarded отклоняется.

JSON-доказательства находятся в [qa/t1-sdk](../qa/t1-sdk/). SDK-сценарии не требуют
изменений production-кода. Проверка типов, production-сборка и все 188 тестов
повторно проходят.

### Границы результата и проверка перед публикацией

Это **приёмка интеграции с официальным dev-адаптером**, не приёмка на площадке.
Сам адаптер Яндекса хранит `setData/getData` в `localStorage` под
`webgames-dev-adapter`, рисует тестовые рекламные окна, а `on()` только пишет лог.
Поэтому сетевое облако, live-рекламу и настоящие `game_api_pause/game_api_resume`
он не проверяет. Перекрытие SDK-паузы с рекламой и вкладкой проверено контрактными
тестами и `pause-flow.ts` с тестовым двойником, как указано выше.

После создания черновика, **до публикации**:

- Запустить ту же сборку в iframe черновика с production SDK и убедиться,
  что fallback в `LocalPlatform` не происходит.
- Подтвердить запись и загрузку облачного сейва в чистом браузерном профиле.
- Проверить реальную рекламу: закрытие без награды, досмотр и одно начисление,
  восстановление лимита после перезагрузки, fullscreen close/error/offline.
- Получить реальные события pause/resume от площадки и проверить бой, звук,
  доход и «Досчитать», в том числе при перекрытии со скрытой вкладкой и рекламой.

## Воспроизведение

```bash
npm ci
npm run build
npm test
npm run preview -- --host 127.0.0.1 --port 4173
# В другом терминале; CHROME при необходимости указывает установленный Chromium:
node --import tsx tools/qa/run-integrity.ts http://127.0.0.1:4173/
node --import tsx tools/qa/pause-flow.ts http://127.0.0.1:4173/
CHROME=/usr/bin/chromium npm run qa:e2e
```

Для локальной SDK-приёмки (Node.js с `--use-env-proxy`, OpenSSL, Chromium):

```bash
npm install --prefix work/yandex-sdk --cache ./work/npm-cache --no-save @yandex-games/sdk-dev-proxy@0.0.2
node --use-env-proxy tools/qa/yandex-dev-server.cjs
# В другом терминале; сертификат генерируется при старте сервера:
YANDEX_QA_CERT=work/yandex-sdk/localhost.crt node --import tsx tools/qa/yandex-live.ts https://localhost:8080/ qa-out/yandex-init.json
YANDEX_QA_CERT=work/yandex-sdk/localhost.crt node --import tsx tools/qa/yandex-dev-flow.ts https://localhost:8080/ qa-out/yandex-dev-flow.json
```

Для сети нужны `yastatic.net`; для последующего запуска на площадке также
`yandex.ru` и `games.s3.yandex.net`. Приватный ключ локального сертификата,
пакет dev-proxy и рабочие browser-профили не включаются в коммит.
