# T1 — материалы к рецензии

Дата: 04.11.2026. База: `17d7070`, ветка `t1/gameplay-integrity-and-sdk-pause`.
Изменения готовы к рецензии. Слияние ожидает проверки настоящего Яндекс SDK:
доступ к его ресурсам в текущей среде блокирует сетевой прокси.

## Поведение после изменения

- Загрузка не принимает повторяющихся участников, некорректную глубину, битые
  ссылки карты/очереди/журнала, неполные стадии и повреждённый RNG.
- Повреждённый activeRun очищается только после создания копии исходного сейва.
  При отказе резервной записи перезапись прогресса отключается; гильдия не обнуляется.
- Вход в узел, исход/продолжение события и rewarded-воскрешение сохраняются сразу.
- SDK, вкладка, модальное окно и рекламный ролик независимо удерживают паузу.
  Она распространяется на бой, звук, экономику и режим «Досчитать». Старый View
  после закрытия не применяет незавершённое действие.
- Подписка SDK выполняется до ожидания игрока. GameplayAPI.start следует после
  LoadingAPI.ready и отражает активную экспедицию и общую паузу.
- Победа завершает семь узлов, включая небоевые. Засада и элитная награда не
  добавляют второй узел; проигранный бой не завершает текущий. Старые активные сейвы
  получают корректный счётчик, уже выданные исторические итоги сохраняются.

Формат GameState остаётся v2; `completedNodes` необязателен для старых сейвов.
Параметры баланса, составы встреч и ассеты не менялись.

## Проверка настоящего SDK: блокер среды

По просьбе владельца использовано собственное окружение и официальный пакет
`@yandex-games/sdk-dev-proxy@0.0.2` с production-сборкой игры и `--dev-mode`.
Пакет установлен во временную папку, не является зависимостью игры.

Этот режим получает SDK-адаптер с
`http://yastatic.net/s3/games-static/sdk-dev/yandex-dev-adapter.js`.
Официальный proxy запущен с `node --use-env-proxy`, чтобы сохранить сетевую
политику среды. Сертификат пакета без имени хоста заменён именным локальным
сертификатом; глобальная проверка TLS не отключалась.

Результат `/sdk.js`: **HTTP 403**. Диагностический запрос получил тело
`Domain forbidden`. Браузерный `tools/qa/yandex-live.ts` записал `status: blocked`
и завершился кодом 2. Настоящий SDK не инициализировался; доступная локальная
игра не засчитывается как успешная проверка SDK. Также блокируется чтение
предоставленной ссылки документации на `yandex.ru`.

`@types/ysdk@1.2.0` проверяет TypeScript-контракт адаптера, но не заменяет runtime.
Реальные реклама, облачные записи и возобновление по событиям площадки остаются
непроверенными. Разрешённый доступ нужен к `yastatic.net` для dev-mode; для полного
запуска на площадке также к `yandex.ru` и `games.s3.yandex.net`.

## Воспроизведение

```bash
npm ci
npm run build
npm test
npm run preview -- --host 127.0.0.1 --port 4173
# В другом терминале; CHROME при необходимости указывает установленный Chromium:
node --import tsx tools/qa/run-integrity.ts http://127.0.0.1:4173/
node --import tsx tools/qa/pause-flow.ts http://127.0.0.1:4173/
CHROME=/usr/bin/chromium npm run qa:e2e
```

Для настоящего SDK после настройки сети:

```bash
npx @yandex-games/sdk-dev-proxy --path ./dist --port 8080 --dev-mode
node --import tsx tools/qa/yandex-live.ts https://localhost:8080/ qa-out/yandex-live.json
```

Для собственного доверенного сертификата можно указать `YANDEX_QA_CERT=/путь/local.crt`:
браузер доверяет только его публичному ключу. `yandex-live.ts` не подменяет SDK или
сетевые ответы, требует платформу `yandex` и не принимает переход в LocalPlatform
за успешную проверку. Успех этого начального probe ещё требует последующей ручной
приёмки реальных рекламы, облачного сохранения и pause/resume на площадке.
