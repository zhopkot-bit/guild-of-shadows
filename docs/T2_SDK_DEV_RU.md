# T2: приёмка официального SDK dev-адаптера

Дата: 09.11.2026. Продолжение `T2_HANDOFF_RU.md`, ветка
`t2/runtime-handoff-2026-11-09`. Владелец подтвердил, что черновика Яндекс Игр
пока нет. Проверена production-сборка `dist-yandex/` с обязательным SDK.

## Результат

Официальный `@yandex-games/sdk-dev-proxy@0.0.2 --dev-mode` отдаёт SDK по
`/sdk.js`. Исходники пакета, SDK, методы, callbacks и сетевые ответы не подменяются.
Обёртка сервера задаёт временный именной TLS-сертификат и отключает автоматическое
открытие браузера. Chromium доверяет только ключу этого локального сертификата;
системная проверка TLS не отключается. Зависимости и сертификат находятся в
игнорируемой папке `work/`.

Загрузчик `https://games.s3.yandex.net/sdk.js` и официальный dev-адаптер
`http://yastatic.net/s3/games-static/sdk-dev/yandex-dev-adapter.js` ответили HTTP 200.
SHA-256 dev-адаптера:
`b0e5af365b02f7afed31efa0a03f9527fc0a1d4cbf0f19738a771581e76e4cc5`.
Доступность production-загрузчика сама по себе не подтверждает инициализацию
SDK: ему нужен iframe площадки. Для локального запуска использован официальный dev-режим.

На 1366×768 прошли шесть проверок без ошибок JavaScript:

1. Приложение использует `YandexPlatform`; `LoadingAPI.ready` предшествует
   `GameplayAPI.start` в активном забеге.
2. Официальное тестовое rewarded-окно останавливает доход и GameplayAPI.
   Раннее закрытие возобновляет их, герой остаётся павшим, лимит воскрешения сохранён.
3. Закрытие без награды не меняет золото. Повторное нажатие во время ролика
   не создаёт второй запрос.
4. Досмотр добавляет ровно 840 золота из исходной награды. Reload сохраняет
   `doubled`, не добавляет золото повторно и не возвращает кнопку удвоения.
5. После фактической записи `setData` удаляется только игровая копия `gos.save`.
   Reload через `getData` восстанавливает тот же забег, золото и число экспедиций.
6. Fullscreen проверен через сборку исходного `YandexPlatform`, поскольку в UI
   пока нет его вызова. Официальные callbacks включают/снимают паузу;
   перекрывающий rewarded отклоняется.

Машиночитаемый результат — `qa/sdk-dev-2026-11-09/sdk.json`.
Повторные 20 браузерных сценариев восстановления и рекламы с имитацией SDK —
`qa/sdk-dev-2026-11-09/reliability.json`. Типизация, 167 тестов в 16 файлах,
обе сборки и строгая проверка арт-реестра прошли. Сводка и контрольные суммы
сборок — `qa/sdk-dev-2026-11-09/validation.json`.

## Воспроизведение

Проверено на Node.js 24.19.0, Chromium и OpenSSL. Node должен поддерживать
`--use-env-proxy`, чтобы официальный прокси сохранял сетевые настройки окружения.

```bash
npm ci
npm run build:yandex
npm run qa:saves
npm install --prefix work/yandex-sdk --cache ./work/npm-cache --no-save @yandex-games/sdk-dev-proxy@0.0.2
npm run qa:sdk-server
```

В другом терминале:

```bash
CHROME=/usr/bin/chromium npm run qa:sdk-dev
```

По умолчанию сервер отдаёт `dist-yandex/` на `https://localhost:8080/`.
Другой порт и каталог: `npm run qa:sdk-server -- 8081 dist-yandex`.
Проверка с явными параметрами:

```bash
YANDEX_QA_CERT=work/yandex-sdk/localhost.crt CHROME=/usr/bin/chromium npm run qa:sdk-dev -- https://localhost:8081/ qa-saves qa-out/sdk-dev/report.json
```

Скрипты находятся в `tools/qa/sdk-dev/`. Сервер опирается на подход T1
из коммита `3f897cde`; код и изменения T1 в эту ветку не переносились.

## Пакет и интеграция

Workflow `Checks` сохраняет содержимое `dist-yandex/` в артефакт `yandex-draft`
после успешных основных проверок. При скачивании ZIP `index.html` должен лежать
в корне. Пакет предназначен для будущей загрузки в черновик; публикация игры
этой проверкой не выполняется.

На момент продолжения `origin/main` остаётся `17d7070` и входит в историю T2.
Для исходного коммита передачи `5b3e777` подтверждён успешный GitHub Actions:
https://github.com/zhopkot-bit/guild-of-shadows/actions/runs/42589910818
Все три задания (`checks`, `browser (webgl)`, `browser (canvas2d)`) успешны.
Этот запуск относится к `5b3e777`, а не к последующим изменениям SDK-проверки.

Открытый PR T1 #25 пересекается с T2 в платформенном адаптере, паузе,
восстановлении боя и QA-инструментах. Интегратору нужно согласовать реализации,
сохранив инварианты T2: один активный `setData`, запрет записи до чтения облака,
защиту более новых сейвов, независимые причины паузы и отмену действий старого View.
В `validation.json` перечислены 15 пересекающихся путей относительно общей базы.

## Что ещё требует площадки

`platformAcceptance: not_run`. Dev-адаптер хранит данные в localStorage
`webgames-dev-adapter`, рисует тестовые рекламные окна, а `on()` только логирует.
Этот прогон подтверждает интеграцию приложения с официальным dev-адаптером.
Реальные `game_api_pause/game_api_resume`, сеть облака, реклама площадки,
синхронизация двух устройств и производительность физических телефонов
остаются непроверенными. Для них нужны черновик Яндекс Игр и реальные устройства.
Воспроизводимые имитации отказов остаются в `qa:reliability` и `qa:platform`.
