# Бран v0.5: интеграция и повторная проверка

26.10.2026. Ветка `art/bran-v05-rig`, база PR — `feat/artpack-portrait-overrides` (PR #2). **Черновая поставка; художественная приёмка не завершена. В main ничего не объединялось.**

Согласованная внешность сохранена в `concept.png`. После смены облачной среды незапушенные изображения и отчёты оказались недоступны. Нарезка и крипта заново созданы по сохранённым референсам, код восстановлен из опубликованных веток и истории работы. Результаты старой среды не засчитываются как проверка этой поставки: ниже описаны повторные проверки восстановленных файлов. Новая нарезка и окружение требуют отдельной визуальной приёмки.

## Что сделано

- Бран снова коротковолосый, в тяжёлых доспехах и синем шарфе, со щитом с золотым крестом. Сохранён канонический игровой портрет; групповой арт не заменялся. Точное совпадение лица и пропорций остаётся предметом художественной оценки.
- DragonBones JSON 5.5: 24 кости, 23 слота, отдельные цепочки плечо/предплечье/кисть и бедро/голень/стопа с двух сторон. Используются только поддерживаемые игровым рантаймом image-слоты и преобразования, без IK/FFD.
- Шесть клипов при 24 кадрах/с: idle — 48 кадров; attack — 20, impact на 10; cast — 18, impact на 7; hit — 9; death — 24; victory — 30. Удар вызывает заметное отклонение; смерть заканчивается горизонтальной фигурой с согнутыми коленями.
- Габариты стоящей фигуры `layoutAabb` отделены от полной области отрисовки `aabb`. Итоговые границы: стойка `(-320, -1515, 780, 1515)`, отрисовка `(-425, -1547, 1818, 1547)`. Размах оружия и падение больше не раздувают область выбора и пятно контакта с полом. Старые риги без новых метаданных сохраняют прежнее поведение. Код и три теста совместимости перенесены из PR #3.
- `revive()` включает idle: раньше прозрачность восстанавливалась, но риг мог остаться в последнем кадре смерти.
- Четыре самостоятельных слоя крипты: дальние своды/туман; колонны/статуя/свечи; единственный мокрый каменный пол; узкие передние каменные края. Параллакс 0.3/0.7/1.0/1.6. Три игровых источника света сопоставлены со свечами.
- Предоставлены исходные генеративные PNG, реальный многослойный PSD и ORA, скрипты упаковки, скелета и анимации. PSD Брана содержит 23 слоя, крипты — 4.

## Найденные ошибки и исправления

1. Воскрешение оставляло риг в death: добавлен возврат в idle и проверка в живой сцене.
2. Полные габариты анимации влияли на выбор героя и ширину контактной тени: введены независимые размеры стоящей фигуры.
3. Прежний E2E мог завершиться по лимиту 400 шагов с пустым `issues`, не дойдя до итогов. Теперь обязателен `completed: true`, а любая ошибка/незавершённость даёт ненулевой exit code. Для медленного программного рендеринга доступен `QA_MAX_STEPS=1200`; проверка завершения сохраняется.
4. При экспорте PSD был обнаружен обратный порядок слоёв. Экспорт исправлен с учётом различий PSD/ImageMagick и ORA, выполнен реальный импорт и сравнение пересобранной проекции в GIMP.
5. Передний план выходил за крайние 60 px: выполнена генеративная правка. Проверка прозрачности не ослаблялась; маски не подрезались кодом ради прохождения.
6. В деталях голени/стопы повторялся участок высокого сапога: границы исходных регионов и размеры стоп уточнены. Общая перспектива обуви ещё требует художественной доводки.

## Незакрытые пункты

- **Нет нативного `.dbproj` и оригинальных мастеров фигуры/портрета.** Установленного редактора DragonBones в среде нет. Скрипты и DragonBones JSON предоставлены, но не выдаются за нативный проект. Используется штатный игровой портрет 256×320.
- **PSD — редактируемая сборка генеративных деталей.** Холст Брана 1200×1600, части увеличиваются из атласа 1536×1024. Это не исходная ручная живопись требуемой детализации. Источники крипты 1672×941 увеличены до 1920×1080; мастера 2560×1440 нет.
- На поясе, коленях, руке и обуви заметен характер сборки. Пропорции сапог и направление ступней, перекрытия ремней/лат, перспектива щита и единый свет требуют ручной ретуши. Чистота альфы при всех позах окончательно не принята.
- Падение заканчивается лёжа, но вращение корпуса и распределение веса остаются механичными. Нужны художественная доводка контакта с полом и вторичного движения плаща, переходов attack/victory.
- У крипты остаются генеративные неровности камня/капителей и различие перспективы пола и архитектуры; центральная свеча частично скрыта переходом пола. Нужна композиционная приёмка. Отсутствие копии пола в far исправляет прежнюю проблему дублирования, но не заменяет оценку параллакса художником.
- На 1024×768 и телефоне существующий HUD частично перекрывает персонажей; это отдельная доработка компоновки UI.
- Не проверены Safari/Firefox, физический телефон, производительность на слабом устройстве, импорт JSON в DragonBones Editor, открытие PSD в Adobe Photoshop. GIMP работал без интерфейса, с предупреждениями плагинов/завершения; фактический импорт и экспорт проекции проверены.

Gate из PR #3 сохранён, имена костей и пути приведены к фактическим файлам; PSD указан как допустимый многослойный формат. Он ожидаемо не проходит без трёх оригиналов. Фиктивные `.dbproj`/мастера не создавались. Наличие файла само по себе не подтверждает подлинность: после поставки нужно открыть исходники в редакторе и провести художественную приёмку. CI `bran-art-contract` не должен считаться успешно пройденным.

## Воспроизведение

```bash
npm ci
python3 tools/art/build_bran_v05.py
npx tsx tools/art/ground_bran_v05.ts
python3 tools/art/build_crypt_v05.py
python3 tools/art/export_bran_v05_source.py
npm run typecheck
npm test
node tools/art/validate_pack.mjs public/art/v17/art-pack.json --strict
npm run build
npm run qa:saves
npm run dev -- --host 127.0.0.1 --port 5173
```

Экспорт требует Pillow и ImageMagick (`convert`). Браузерные проверки в другом терминале:

```bash
export CHROME=/usr/bin/chromium
node tools/qa/bran-v05.mjs http://127.0.0.1:5173/ qa-saves/battle.json qa-out/bran-v05-webgl
QA_FORCE_CANVAS=1 node tools/qa/bran-v05.mjs http://127.0.0.1:5173/ qa-saves/battle.json qa-out/bran-v05-canvas
node tools/qa/bran-v05-scenes.mjs
QA_MAX_STEPS=1200 node tools/qa/e2e.mjs http://127.0.0.1:5173/ qa-out/e2e-bran-v05 1366 768
node tools/qa/bran-v05-gate.mjs . docs/qa/bran-v05-contract.json --strict
```

Последняя команда ожидаемо завершается с кодом 1 из-за отсутствующих исходников. Проверка PSD: `gimp-console-3.0 -n -i -d -f -s --batch-interpreter=python-fu-eval -b 'exec(open("tools/art/check_psd_import.py").read())' --quit`; она сохраняет отчёт и проекции в `qa-out/psd-import`.
