# Повторная работа по рецензии PR №16

Источник: [повторная рецензия](https://github.com/zhopkot-bit/guild-of-shadows/pull/16#pullrequestreview-5709362470) и [решение заказчика с заданиями](https://github.com/zhopkot-bit/guild-of-shadows/pull/16#issuecomment-6517569555).

**Рук, `shoot`.** Лицо и волосы взяты из нового генеративного варианта по референсам `aim` и портрета. В GIMP 3 с помощью скрипта и масок этот фрагмент объединён с предыдущим рисунком: за пределами области головы сохранён принятый силуэт. Лишняя диагональ тетивы замаскирована, тонкая линия между концами дуги помещена на отдельный слой. Это кандидат для художественного просмотра; полное совпадение лица с `aim` при наложении не заявляется.

**Костяной король I, `prepare`.** После разрешения пользователя исходные кисти и меч подняты вместе на 50 пикселей без изменения формы и хвата. Для полного клинка сверху добавлено 80 пикселей холста. Предплечья локально подогнаны с помощью генеративного варианта; череп с короной перенесён из `idle`, ворот соединён с латами, на корону добавлено тусклое красное тление. Слои собраны в GIMP 3 с помощью скрипта и масок, свободной ручной прорисовки не было.

[Подготовка умения](../../art-sources/poses/boneKing/proposals/prepare.png) · [послойный PSD](../../art-sources/poses/boneKing/layers/prepare-head-lift-2026-10-30.psd) · [сравнение со стойкой](boneKing-poses-v2/head-comparison.png) · [запрос и сведения о сборке](KING_HEAD_LIFT_2026_10_30.json). Изображение ожидает художественного просмотра.

Нора, чародей, страж, гоблин, волк и король II не перерисовывались, согласно решению в рецензии. Тон волка и общие технические проверки остаются на завершающий этап.
