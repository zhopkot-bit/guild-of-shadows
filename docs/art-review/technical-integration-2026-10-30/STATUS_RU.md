# Технический проход поз: состояние на 04.11.2026

Облик 47 поз PR №16 принят [рецензией 30 октября](https://github.com/zhopkot-bit/guild-of-shadows/pull/16#pullrequestreview-5710438793). Сборочный проход реализован локально; полная техническая приёмка остаётся открытой.

## Сделано

- Из утверждённых `proposals` воспроизводятся одинаковые PNG-холсты в `masters/` для восьми наборов, высота каждого ≥1448 px. Исходники не заменены. Генерируемые мастера исключены из Git, чтобы не дублировать около 100 МБ; источник и параметры преобразований сохранены.
- Выравнивание опоры и индивидуальный масштаб заданы в `art-sources/poses/technical-layout.json`. `cast`/`victory` Норы увеличены; `hit` стража проверен по масштабу частей фигуры, увеличение до высоты стойки не применялось из-за наклона и согнутых ног.
- У волка в `windup` RGB output white = 0,86 для согласования тона со стойкой. Альфа ≤1/255 удалена как практически прозрачный фоновый шум; остальные края сохраняются с интерполяцией. Это техническая обработка, без генерации нового рисунка.
- Экспортированы 47 WebP высотой 768 px и подключены в `public/art/v17/art-pack.json`. Для волка качество 86, остальных — 88. Параметры воспроизводимы.
- Строгий валидатор реестра проходит; отдельная проверка силуэтов WebP проверяет опорную линию и поля, поскольку штатный валидатор делает эту проверку только для PNG. Результаты — `registry-validation.json` и `silhouette-checks.json`.
- Подготовлены восемь `*-runtime-sheet.png` с единым масштабом внутри набора.
- На 04.11.2026 `npm test` проходит: 129 тестов в 14 файлах; `npm run build` проходит (TypeScript и Vite). Эти проверки не подтверждают браузерную приёмку.
- Первый браузерный прогон выявил обрезание короля. В расчёт размера сцены добавлено общее ограничение по холстам обеих фаз и согласование роста героев/босса. Новое ограничение покрыто модульной проверкой.

## Что не подтверждено

Повторный браузерный прогон после исправления босса не выполнен: в текущем окружении сервер получает `listen EPERM`, Chromium прекращает запуск с `setsockopt: Operation not permitted`. Запрос расширенного сетевого доступа для сервера был прерван пользователем. Это ограничение окружения, а не успешный тест и не отказ автоматической проверки безопасности.

Сохранённый `renderer-before-fix.json` относится к прежнему размещению: mixed/mage прошли на 1920×1080 и 667×375, босс I не прошёл на обоих разрешениях, босс II — на 1920×1080. Его нельзя считать результатом исправленного кода. Движения, impact, настоящий цикл действий, Canvas 2D и полный регресс после исправления требуют отдельного запуска.

## Ограничения для следующей приёмки

1. У Норы `shoot` исходный край сапога касается нижней границы (26 пикселей альфы >24), у гоблина `hit` край плаща касается правой границы (103 пикселя). Поля нового холста не восстанавливают отсутствующий рисунок. Есть также мелкие касания у короля I `strike`/`down` и короля II `hit`; точные числа в отчёте.
2. Высокая подготовка короля при сохранении согласованного размера головы требует общего холста, где стойка занимает 66,7%, вместо 75–85% ТЗ. Остальные наборы — около 79–80%. Требуется согласованное исключение либо художественное решение, а не ложная отметка соответствия.
3. Павший волк выходит на 0,77 высоты стойки от опоры при норме 0,60. Требуется проверить пересечение с соседями и согласовать решение; уменьшать только павшую фигуру незаметно для заказчика не следует.
4. Увеличение холста/интерполяция источников 1024 px не создаёт новых деталей. Исходное разрешение и масштаб записаны в `normalization.json`.
5. Бран остаётся в отдельном PR №11; арены и дальнейший комплект ТЗ этим проходом не завершены. Публикация и объединение PR не выполнялись.
