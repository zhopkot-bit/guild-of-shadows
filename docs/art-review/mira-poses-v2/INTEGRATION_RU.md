# Мира: завершённая техническая интеграция

28.10.2026. Все восемь поз подключены к обычному игровому реестру: `public/art/v17/heroes/mira/poses/poses.json`. Параметр `artpack` для игры больше не нужен. В новой игре Миру можно добавить в отряд на вкладке «Отряд».

Принятый пользователем `strike` v9 сохранён без художественных изменений. SHA-256 исходника: `e845979af58255941793c35590dfba38e9fde1f95169f3fc2e2191af4feb2325`. Игровые WebP совпадают с проверенным QA-экспортом; восемь изображений 537×768 занимают около 630 КиБ.

## Исправления отображения

На 667×375 Мира в первом месте отряда выходила за левый край. Размещение теперь учитывает полный холст позы и сдвигает строй вместе, сохраняя расстояния между героями и плашками. При отдаче, замахе и приближении камеры цельная поза удерживается внутри кадра. На экране героя масштаб учитывает запас холста под оружие.

В диагностике `?qa=1` появилась текущая поза. Это позволило подтвердить переключения при настоящем нажатии кнопок атаки и умения в production-сборке.

## Проверки

- `npm test`: 127 тестов, 13 файлов, успешно.
- `npm run build`: TypeScript и production-сборка успешно.
- [Строгий валидатор основного реестра](runtime-validation.json): ошибок и предупреждений нет.
- [WebGL](integration/pose-checks.json): 1920×1080, 1366×768, 1024×768, 844×390, 667×375; 40 статичных показов и 1043 кадра движения. Проверены выстрел, выпад, тяжёлое попадание, победа и падение. Обрезания непрозрачной области и ошибок рендерера не обнаружено.
- [Canvas 2D](integration/canvas2d-checks.json): 667×375, восемь поз и 200 кадров движения; успешно.
- [Production-цикл](integration/game-flow.json): на 1920×1080 и 667×375 проверены настоящие кнопки выстрела и «Точного выпада», позы `aim → shoot` и `windup → strike`, восстановление HP/раунда/хода после перезагрузки, продвижение автобоя, штатная кнопка «Досчитать», победа над боссом, возврат в гильдию и экран Миры с закрытием по Esc. Все девять файлов игрового пакета загружены без ошибок.

Полное прохождение босса только автобоем не заявляется проверенным: первый такой прогон на программном WebGL превысил таймаут. Финальный воспроизводимый сценарий проверяет реальный раунд автобоя и завершает бой штатным досчётом. Производительность устройства игрока этим прогоном не измерялась.

## Воспроизведение

```bash
QA_PARTY=mira,rook,nora node --import tsx tools/qa/make-saves.ts qa-saves/mira
npm test
npm run build
node tools/art/validate_pack.mjs public/art/v17/art-pack.json --strict

# При запущенном npm run dev:
CHROME=/usr/bin/chromium node tools/qa/mira-integration.mjs
NO_WEBGL=1 VIEWPORTS=667x375 CHROME=/usr/bin/chromium node tools/qa/mira-integration.mjs http://127.0.0.1:5173/ qa-saves/mira/battle.json qa-out/mira-canvas2d

# При запущенном npm run preview -- --host 127.0.0.1 --port 4173:
CHROME=/usr/bin/chromium node tools/qa/mira-flow.mjs
```

Исходные PNG, история отклонённых версий и приёмка атаки сохранены в `art-sources/poses/mira/`. Приёмка остальных рисунков не подменяется техническими проверками. PSD/KRA и ручная ретушь не заявляются выполненными. Изменения поставляются через PR, без автоматического объединения в `main`.
