# Журнал изменений — Dark Fantasy baseline

Версия патча: v1.3 • 23.10.2026. Эта итерация продолжает v1.2 и переносит утверждённый художественный эталон в исходники интерфейса.

## v1.3 — визуальная интеграция концепт-артов

1. Добавлен набор оптимизированных WebP-ресурсов: цитадель, сцены подземелий, две формы босса, пять построек, портреты героев и противников.
2. Экран гильдии теперь использует большой кинематографичный баннер и иллюстрированные карточки построек.
3. Экран отряда получил атмосферную шапку и растровые портреты.
4. Экран экспедиции получил фон руин; интерактивные узлы карты остаются реальными элементами DOM/SVG.
5. Фон арены обычного боя использует крипту; сцена босса меняется между фазами I и II.
6. CSS доработан под узкие мобильные экраны и wide desktop; добавлены латунные рамки, чернильные панели и затемнение, чтобы сохранить контраст текста.
7. Для растровых портретов добавлен fallback при ошибке загрузки.
8. Созданы постановочные макеты `Art_Direction_Preview_v1.3` по тем же ресурсам. Они не являются записью/скриншотами запуска приложения.
9. `package.json` обновлён до версии `0.1.3`.

## Ограничения проверки v1.3

- `tsc -p tsconfig.src.json` — PASS.
- `npm install --ignore-scripts --no-audit --no-fund` не завершился по тайм-ауту; `npm test` и `npm run build` не подтверждены.
- Интеграция ассетов присутствует в исходниках, но должна быть проверена в production build и в Яндекс.Играх перед публикацией.

# Технический baseline «Гильдия Теней» — Dark Fantasy

Версия патча: v1.2 • 21.10.2026. Это техническая итерация исходного прототипа, не релизная сертификация.

## Изменения этой итерации

1. **Экспедиции без жетонов**
   - Жетоны больше не блокируют запуск и не списываются.
   - Убраны жетоны из основного UI и удалён рекламный CTA «получить жетон».
   - Поля жетонов оставлены в структуре сейва для совместимости со старыми данными; экономические helper-функции пока не удалены, чтобы не ломать прежние тесты/инструменты.

2. **Редкость не заменяет качество билда**
   - Боевые множители редкости приведены к `1.0` для всех уровней редкости.
   - Стоимость улучшения героя теперь зависит от уровня, но не умножается на редкость.
   - Существующие поля `rarity` и визуальные обозначения сохранены для коллекционной/косметической семантики.

3. **Безвозвратная гибель отменена**
   - Павшие герои получают временную травму после небезопасного забега.
   - Герои больше не удаляются из отряда и коллекции из-за случайного броска судьбы.
   - При загрузке старого сейва статус `lost` мигрирует в `wounded` на 30 минут, чтобы не закреплять старое разрушительное правило.
   - Поля `lost`/`heroesLost` сохранены как совместимые legacy-поля, но новая логика их не увеличивает.

4. **Фиксированный стартовый ростер**
   - В новом сохранении четыре стартовых героя имеют канонические имена: Бран, Мира, Рук и Нора.
   - Состав отряда на старте: Бран, Мира и Нора; Рук доступен в коллекции.

5. **Экономика постов**
   - Библиотека теперь усиливает HP отряда вместо неактуального шанса избежать постоянной смерти.
   - Таверна даёт бонус к доходу, а не скорости жетонов.
   - Эффекты одинакового типа суммируются по постам с индивидуальными пределами.

6. **Сохранение незавершённой экспедиции**
   - Добавлена сериализация/восстановление активного забега вместе с состоянием RNG забега и боевого движка.
   - Активный забег хранится в поле `activeRun` внутри общего сейва, поэтому использует тот же локальный/облачный механизм платформы.
   - Добавлена валидация восстановленного забега, чтобы повреждённый JSON не принимался как рабочее состояние.
   - Результат завершённого забега кешируется в `Run.summary`; повторный вызов `finishRun` возвращает прежний результат без повторной выдачи наград.

7. **Двухфазный босс и честный телеграф атак**
   - Страж гробницы переходит во II фазу при падении здоровья до 50% или ниже, если он выжил после удара.
   - Во II фазе меняется имя, атака повышается на 20%, скорость — на 1, а умение «Удар по площади» превращается в более сильный «Сокрушительный удар» (+25% к множителю урона).
   - UI показывает фазу босса и его ожидаемое следующее действие; перед атакой показываются предупреждение и тип цели (один герой или весь отряд).
   - Событие перехода отображается в боевом журнале и сохраняется в журнале боя.
   - Старые сохранения без `bossPhase` автоматически приводят босса к нужной фазе при восстановлении боя, если его HP уже ниже порога.
   - Умение босса копируется при изменении: глобальная таблица `SKILLS` остаётся неизменной.

8. **Тесты регрессии обновлены**
   - Проверка отсутствия расхода жетонов.
   - Проверка равенства боевых характеристик героев разной редкости.
   - Проверка временных травм вместо постоянной гибели.
   - Проверка сериализации RNG и активного боя.
   - Проверка идемпотентности выдачи итогов и миграции старого `lost`.
   - Проверка фазового перехода босса, телеграфа навыка, сохранения `bossPhase` и миграции старого боя.
