# Источники Брана v0.5

Основа — согласованный пользователем генеративный концепт `docs/art-review/bran-v05/concept.png`, созданный по каноническим sprite/portrait Брана. После смены облачной среды незапушенная нарезка утрачена; этот `cutout-atlas.png` заново создан image_gen 26.10.2026 по тому же согласованному концепту. Он требует отдельной художественной приёмки.

Исходная нарезка `cutout-atlas.png` (1536×1024) содержит генеративно восстановленные скрытые области. Дополнительный `seam-parts.png` (1536×1024) создан по согласованному концепту: отдельные грудная броня, единственный пояс и две тканевые детали без повторных ремней. Скрипт извлекает детали и сохраняет `packed-atlas.png` (2048×1111) без потерь, а для игры — WebP quality=90 (571046 байт). Четыре новые детали уменьшаются при сборке фигуры; остальные по-прежнему увеличиваются. Метаданные `texture-regions.json` и скрипты `tools/art/build_bran_v05.py`, `ground_bran_v05.ts` задают части и анимацию. `bran_layers.psd` и `.ora` — редактируемая сборка из 23 слоёв на холсте 1200×1600; часть деталей увеличена из исходной нарезки. PSD и игровой WebP используют одни и те же регионы `packed-atlas.png`. Пояс располагается поверх тканевых деталей, чтобы скрыть их верхние края. Это не исходная ручная живопись 1400–1600 px. Нет оригинального мастера фигуры, мастера портрета и нативного `.dbproj`.

Экспорт слоёв: `python3 tools/art/export_bran_v05_source.py`. Порядок PSD — снизу вверх для ImageMagick, ORA — сверху вниз. Проверка импорта: `tools/art/check_psd_import.py` внутри GIMP 3. Photoshop и DragonBones Editor здесь не проверялись. Не выдавать JSON за `.dbproj` и не считать наличие PSD закрытием всей художественной приёмки.
