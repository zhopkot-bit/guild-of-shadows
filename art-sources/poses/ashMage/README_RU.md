# Пепельный чародей: художественные исходники

Шесть кандидатов поз по ТЗ: idle, aim, shoot, prepare, hit, down. Канон — существующая фигура; остальные позы построены от нового idle. Художественная приёмка пользователем пока не зафиксирована.

В prepare жезл закреплён у пояса, чтобы освободить обе руки. У shoot укорочены развевающиеся концы ткани для полного силуэта.

Все изображения созданы и исправлены через image_gen. Ручная ретушь не выполнялась. Оригиналы, запросы и история источников сохранены; предыдущие варианты — alternatives.

Выравнивание, единый размер холста, экспорт, интеграция и технические проверки отложены на общий завершающий этап.
