# Нора: художественные исходники

Семь PNG-кандидатов: idle, aim, shoot, cast, hit, down, victory. Канон — существующие sprite.webp и portrait.webp Норы; остальные позы опираются на новый idle.

Пользовательская приёмка открыта. Экспорт, интеграция и технические проверки отложены до готовности всего художественного комплекта. Ручная ретушь не выполнялась; изображения созданы и исправлены через image_gen.

История источников — provenance.json; запросы — *prompt*.json. Первоначальный shoot с обрезанным посохом сохранён в alternatives.
