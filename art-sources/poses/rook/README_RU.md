# Рук: художественный комплект

Шесть кандидатов по ТЗ: `idle`, `aim`, `shoot`, `hit`, `down`, `victory`. Канон взят из игровых sprite/portrait; новые позы опираются на общую стойку. Выстрел создан на основе прицеливания.

В первой победной позе генератор добавил неверную вертикальную рукоять арбалета. Версия сохранена в `alternatives/`, основной вариант победы создан заново с цельным прямым ложем.

PNG сохранены без программной ретуши. Запросы и происхождение находятся рядом. Это художественные кандидаты, пользовательская приёмка не заявляется. Экспорт, выравнивание, подключение к игре и технические проверки отложены на общий завершающий этап по решению пользователя от 29.10.2026.
