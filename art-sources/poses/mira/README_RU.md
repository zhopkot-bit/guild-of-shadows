# Мира: восемь цельных поз, ТЗ 2.1

Исходные генеративные PNG сохранены в `proposals/`, без скрытого увеличения или ретуши. Канон: `public/art/v17/heroes/mira/sprite.webp`, `portrait.webp` и общий `hero-lineup.webp`. Инструмент — OpenAI image_gen. Запросы и происхождение файлов сохранены рядом.

Набор: `idle`, `aim`, `shoot`, `windup`, `strike`, `hit`, `down`, `victory`. Это художественный пилот Миры; автоматическое принятие Брана на него не распространяется. Ручная доводка и PSD/KRA пока не выполнены.

Фактические мастера — 1086×1448 RGBA. Запрошенный размер генерации 1536×2048 не был выполнен генератором; исходники не увеличивались. Для игры 1448 px разрешены ТЗ §3.3.

Первые отклонённые версии `strike` и `hit` сохраняются в `alternatives/`. Пользователь указал на неполную левую руку в `hit` и некорректные руки в `strike`; переработки выполняются с этими замечаниями.

## Техническая сборка

```bash
python3 tools/art/build_poses.py art-sources/poses/mira/proposals qa-fixtures/mira-poses-v2/mira
node tools/art/validate_pack.mjs qa-fixtures/mira-poses-v2/art-pack.json --strict
node tools/art/build_pose_gallery.mjs mira qa-fixtures/mira-poses-v2/mira/poses.json docs/art-review/mira-poses-v2 'Мира · восемь поз · художественный пилот'
```

`canvasPadding: [32, 24, 32, 24]` добавляет одинаковые прозрачные поля слева, сверху, справа и снизу в пикселях мастера; автоматический запас под масштабирование добавляется отдельно. `alignFeet` выравнивает стоящие позы по вертикали. `victory` масштабируется ×1,10. Точка опоры стойки по горизонтали задана между двумя ступнями (`pivot.x = 0.56`): автоматическая оценка по нижней полосе изображения принимала одну более низкую ступню за центр.

Игровой реестр `public/art/v17/art-pack.json` подключает набор из `public/art/v17/heroes/mira/poses/poses.json`. Он работает в обычной игре без параметра `artpack`; в новой игре Миру надо добавить в отряд. QA-пакет остаётся отдельной копией для сравнения. После пересборки скопируйте восемь WebP и `poses.json` из QA-пакета в игровой каталог и проверьте основной реестр строгим валидатором.
