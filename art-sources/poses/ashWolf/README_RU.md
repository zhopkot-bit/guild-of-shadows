# Пепельный волк: художественные исходники

Пять кандидатов: idle, windup, strike, hit, down. Созданы через image_gen по каноническому sprite.webp и новой стойке. Направление — влево. Пользовательская приёмка не зафиксирована.

У волка осталась серая подложка: подготовка прозрачности и финального размера мастеров ещё не выполнена.

Ручная ретушь не выполнялась. Интеграция, выравнивание и технические проверки отложены на общий завершающий этап. Запросы и история источников сохранены рядом.
