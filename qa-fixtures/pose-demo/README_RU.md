# Тестовый пакет поз (QA)

Технический образец формата, **не утверждённый арт**.

- `bran/` — 8 поз Брана, отрендеренных из рига v0.5 (PR #5) инструментом `tools/art/rig_to_poses.mjs` и собранных `tools/art/build_poses.py`: серия удара из 2 кадров с маской свечения клинка, вариант позы урона (`alternatives`), раненая стойка (`wounded`). Поза анфас и скованная пластика унаследованы от рига — так рисовать не надо.
- `goblin_a/`, `goblin_b/` — набор поз гоблина, полученный наклонами и сжатием утверждённого спрайта, и второй облик для двойника «Б» (сдвиг оттенка) — проверка `posesVariants`.
- `vfx/` — синтетические листы пяти эффектов умений (`slash`, `ashBurst`, `heal`, `wave`, `cover`).

Открыть в игре: `npm run dev` → `http://localhost:5173/?qa=1&artpack=/qa-fixtures/pose-demo/art-pack.json`.
