# Сборка и проверки прототипа — v1.3

## Требования
- Node.js LTS (проверено на Node 22)
- npm

## Команды
1. `npm install`
2. `npm run typecheck`
3. `npm test`
4. `npm run sim`
5. `npm run build`

## Проверено в текущем контейнере — итерация v1.3
- `tsc -p tsconfig.src.json` после подключения визуальных ассетов — PASS.
- Проверка перечисленных файлов `public/art/scenes`, `public/art/posts`, `public/art/portraits` — PASS; 23 WebP-ресурса, суммарно около 1.56 MB.
- Проверка разрешения растровых ассетов и формирования четырёх визуальных макетов — PASS.
- Предыдущие проверки логики v1.2: фиксированный ростер, отсутствие списания жетонов, сериализация RNG активного боя/забега, паритет редкости, идемпотентность наград, двухфазный босс; smoke-симуляции 100 экспедиций и 40 боёв с боссом завершались штатно. Эти runtime-сценарии не запускались повторно после v1.3, поскольку изменения этой итерации затрагивают преимущественно UI/арт.
- `npm install --ignore-scripts --no-audit --no-fund` не завершился в отведённое время; повторная попытка v1.3 также завершилась по тайм-ауту.
- `npm test` и `npm run build` в v1.3 не прошли/не подтверждены: зависимости не установлены. Не следует считать этот пакет сертифицированным релизом.
- Визуальные PNG и MP4 в `Art_Direction_Preview` — постановочные макеты и слайд-шоу, не реальные browser captures и не запись интерактивного игрового процесса.
Не считать этот архив сертифицированным релизом. Перед публикацией обязательно установить зависимости, выполнить весь набор команд, проверить сборку внутри Яндекс.Игр и провести тесты на реальных устройствах.
