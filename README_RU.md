# Guild of Shadows — техническая итерация Dark Fantasy v1.3

Этот пакет содержит исходники и регрессионные тесты текущей технической итерации проекта.

## Художественное направление v1.3
- Dark Fantasy концепт-арт закреплён как эталон интерфейса.
- В код подключены WebP сцены цитадели, руин, крипты, двух фаз босса, пяти построек и портретов героев/врагов.
- Экран гильдии, экран отряда, экспедиция и арена босса получили иллюстрированные слои и адаптивные стили.
- Реестр ассетов: `ART_ASSET_MANIFEST_RU.md`; арт-решения: `docs/art-direction-implementation-v1.3.md`.
- Визуальные макеты и 10-секундное видео-презентация находятся в отдельном `Guild_of_Shadows_Art_Direction_Preview_v1.3_RU.zip`; они не являются runtime-скриншотами или реальной записью игрового процесса.

## Важные изменения
- Экспедиции не требуют и не расходуют жетоны.
- Редкость не умножает боевые характеристики и стоимость улучшения.
- Гибель героя заменена временной травмой; старые сохранения с `lost` восстанавливаются.
- Незавершённая экспедиция сериализуется вместе с состоянием генераторов случайных чисел.
- Итоги забега идемпотентны: повторная загрузка экрана не начисляет награды повторно.
- Стартовый ростер именован: Бран, Мира, Рук, Нора.
- У босса есть две фазы, усиление при 50% HP, телеграф следующего действия и миграция старых сохранений.

## Статус проверки
Строгая проверка исходников `tsc -p tsconfig.src.json` после внедрения v1.3-ассетов пройдена. Ранее проведённые runtime smoke-сценарии (включали 40 автоматических забегов и 40 боёв с боссом) пройдены. Полный Vitest-прогон и Vite production build не подтверждены, поскольку установка npm-зависимостей не завершилась. Подробности — в `IMPLEMENTATION_AUDIT_RU.md`, `PATCH_NOTES_RU.md`, `docs/boss-phase-and-telegraph.md` и `docs/art-direction-implementation-v1.3.md`.

## Запуск
С Node.js LTS выполните `npm install`, затем `npm run typecheck`, `npm test`, `npm run sim` и `npm run build`.
